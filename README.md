## Описание

**HypeSportClub** — это современное Android-приложение для управления спортивным клубом. Приложение позволяет клиентам приобретать абонементы и записываться на тренировки, тренерам — управлять расписанием, а администраторам — контролировать все аспекты работы клуба.

### Основные возможности

- 🔐 **Авторизация** — регистрация и вход с разделением по ролям
- 💳 **Абонементы** — покупка и продление абонементов
- 🏋️ **Тренировки** — групповые и индивидуальные занятия
- 👤 **Профиль** — управление личными данными и расчёт ИМТ
- ⚙️ **Настройки** — тёмная тема и мультиязычность (RU/EN)
- 👑 **Админ-панель** — полное управление клубом

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-repo/HypeSportClubMobile.git
cd HypeSportClubMobile
```

### 2. Настройка Firebase

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/)
2. Добавьте Android-приложение с package name: `com.example.mobilka`
3. Скачайте файл `google-services.json`
4. Поместите его в папку `app/`
5. Включите **Firebase Authentication** (Email/Password)
6. Включите **Cloud Firestore**

### 3. Сборка проекта

```bash
# Windows
gradlew.bat assembleDebug

# Linux/macOS
./gradlew assembleDebug
```

### 4. Запуск

Откройте проект в Android Studio и запустите на эмуляторе или устройстве.

## Инструкция пользователя

### Регистрация

1. Откройте приложение
2. Нажмите вкладку **"Регистрация"**
3. Заполните обязательные поля:
   - Фамилия, Имя (обязательно)
   - Отчество (опционально)
   - Дата рождения (формат ДД.ММ.ГГГГ)
   - Пол
   - Рост и вес (для расчёта ИМТ)
   - Цель занятий
   - Email и пароль (мин. 6 символов)
4. Нажмите **"Зарегистрироваться"**

### Покупка абонемента

1. Перейдите в раздел **"Профиль"** → **"Абонементы"**
2. Выберите подходящий абонемент
3. Нажмите **"Оформить"**
4. Подтвердите покупку в диалоговом окне

### Запись на тренировку

1. Перейдите в раздел **"Тренировки"**
2. Выберите вкладку **"Групповые тренировки"**
3. Найдите интересующую тренировку
4. Нажмите **"Записаться"**
5. Для отмены записи нажмите **"Отменить"**

### Просмотр моих тренировок

1. Перейдите в раздел **"Тренировки"**
2. Выберите вкладку **"Мои тренировки"**
3. Здесь отображаются:
   - Индивидуальные тренировки (назначенные тренером)
   - Групповые тренировки (на которые вы записаны)

### Изменение настроек

1. Перейдите в **"Профиль"** → **"Настройки"**
2. Доступные настройки:
   - **Тема**: Светлая / Тёмная
   - **Язык**: Русский / English

## Администрирование

### Создание пользователя

1. Войдите под администратором
2. Перейдите в раздел **"Пользователи"**
3. Нажмите **"+"** в правом нижнем углу
4. Выберите роль нового пользователя
5. Заполните данные
6. Нажмите **"Создать"**

### Создание абонемента

1. Перейдите в раздел **"Абонементы"**
2. Нажмите **"+"**
3. Заполните:
   - Название
   - Описание
   - Стоимость (₽)
   - Срок действия (дней)
   - Эмодзи иконку
   - Список услуг (через запятую)
4. Нажмите **"Создать"**

### Создание тренировки

1. Перейдите в раздел **"Тренировки"**
2. Выберите дату в календаре
3. Нажмите **"+"**
4. Выберите тип тренировки:
   - **Индивидуальная** — выберите клиента
   - **Групповая** — укажите макс. число участников
5. Заполните данные тренировки
6. Нажмите **"Создать"**

### Структура Firestore

```

├── users/                 # Пользователи
```

Файл `firestore.rules` содержит правила доступа к данным. Рекомендуется настроить правила в соответствии с требованиями безопасности.
